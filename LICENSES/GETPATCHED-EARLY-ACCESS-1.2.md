# GetPatched Early Binary Access Terms — version 1.2

These version 1.2 terms apply to official GetPatched binary package files downloaded from
the authenticated early-access APT channel before that package target is
publicly released. Public recipe repositories remain visible. Their
GetPatched-authored files are MIT-licensed, so anyone may build from source
and use or redistribute an independent build under that licence and any
applicable third-party licences.

Every active individual GitHub Sponsors tier qualifies. A one-time sponsorship
qualifies only while GitHub reports it active. Organization sponsorships are
not yet supported because the service cannot securely map an organization
sponsorship to a specific GitHub user; organization membership alone never
grants access. Access ends when GitHub reports that the sponsorship is
inactive. Device credentials are checked against current sponsor status;
signed end-of-cycle cancellation events immediately invalidate cached access,
active-only reconciliation runs every 15 minutes, and stale sponsor snapshots
fail closed.

You may install and use official early binaries for private and commercial
purposes. GetPatched does not permit redistribution, sublicensing, mirroring,
or sharing of official early-channel binary files or access credentials before
the corresponding public release. This restriction governs GetPatched's
official early-channel delivery and does not remove rights granted
independently by upstream or distribution licences. Preserve all third-party
notices and comply with those licences.

When the same verified package target is promoted to the public channel, its
GetPatched-authored contributions are available under the MIT License. Public
promotion uses the already verified package bytes; it does not rebuild them.

By creating an early-channel device credential, you confirm that you have
read and accepted these terms.
