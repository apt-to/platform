GETPATCHED / EARLY BINARY ACCESS

Early binary terms

Version 1.2 · applies only to official GetPatched binary package files downloaded from the authenticated early channel before public release.

Eligibility and access

Every active individual GitHub Sponsors tier qualifies. A one-time sponsorship qualifies only while GitHub reports it active. Access ends when GitHub reports the sponsorship is no longer active. A cancellation scheduled for the end of a paid period remains active until that period ends. A signed end-of-cycle cancellation event immediately invalidates cached access; active-only reconciliation also runs every 15 minutes, and stale sponsor snapshots fail closed. Organization sponsorships are not yet supported because the service cannot securely map them to a specific GitHub user; organization membership alone never grants access.

Permitted use

You may use official early binaries for private or commercial purposes. You may not redistribute, sublicense, mirror, publish, or share those official early binary files or credentials before their corresponding public release.

Public source and third-party rights

GetPatched-authored recipes, patches, tests, and documentation are public under the MIT License from day one. Anyone may build and redistribute an independent build under MIT and applicable third-party licenses. This agreement does not change upstream or distribution copyright, license notices, or other rights in source code or compiled packages. Those third-party terms continue to apply.

When a verified package target is promoted publicly, GetPatched's early-channel restriction ends for that package target. Public promotion uses the same verified package bytes.

Creating an early-channel device credential confirms that you have read and accepted these terms.
